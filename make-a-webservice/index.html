I started doing web-stuff again! There are a gazillion decisions to make when you create even a medium-sized web service. This article is intended to give a small overview.

This is an article I had for quite a while as a draft. As part of my yearly cleanup, I've published it without finishing it. It might not be finished or have other problems.

Quick n' Dirty

You can set up a first page in about 10 minutes, if you have a DigitalOcean account and the domain via namecheap:

  1. Create Docker digital ocean droplet
  2. Add SSH-Key to machine
  3. Clone GitHub repository
  4. Create A-Record in namecheap (takes 24h)

WYSIWYG Editors

I would like to have a WYSIWYG editor. It should support heading types, bold/italic/underline, tables, images, videos from YouTube, file upload and MathJax formulas.

It would be nice if it supported storing / rendering directly from Markdown. If that doesn't exist, I might convert the HTML to Markdown and back with Pandoc.

Decisions

  • Display name, Username or Handle? (Disqus, Kik, Spotify, Twitch)
  • How many characters may a display name have? (e.g. 30 on StackExchange)
  • Where are hard deletes allowed, where only soft deletes?
