Go to the Game: Lightbot 2.0 on Kongregate

Task: Solve the levels

How to play: You can program the Lightbot to move, jump and to switch its light on. By defining functions and using recursion you can keep your program code small. It's a nice online game where you can start to learn programming.

My Record: All Basic and Recursion-Levels done.
