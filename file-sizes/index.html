This is an article I had for quite a while as a draft. As part of my yearly cleanup, I've published it without finishing it. It might not be finished or have other problems.

I was just wondering how long a camera which takes images in 5s intervals and has 256 GB of storage could take photos. This is quite easy to answer as soon as you know the average file size. For that, however, I could not find a good answer in the first 3 Google results. Let's fix that.
