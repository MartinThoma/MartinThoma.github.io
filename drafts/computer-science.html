Data Types

There are primitive data types and data structures which are built from those primitive types.

Type Size in C Value Range
char 1 byte [-128, 127]*
int 4 bytes [-2147483648, +2147483647]*

double 8 bytes [2.3E-308, 1.7E+308]
pointer 8 bytes on 64 bit systems*

Data Structures

Linear Data Structures

Linear Data Structures define an order over the elements. They can be divided into direct access ones (arrays) and sequential access data structures:

  • General: Lists (have a look at mpu/datastructures)
  • LIFO: Stack
    • push(1), push(2), push(3), pop() -> 3
  • FIFO: Queue
    • push(1), push(2), push(3), pop() -> 1
  • Bit-Array (python)

Non-Linear Data Structures

  • Sets: Bloom filters (video, details, Python)
  • Graphs
    • Weighted
    • Acyclic
      • Trees
        • Binary Trees
  • Dictionary / associative array / Maps
  • Bloom Filter: (Python: dablooms and pybloomfiltermmap)
  • Prefix-Tree (Trie)
  • Search Trees
    • Binary search trees: Apparently, they are used within databases, Huffman coding, and the implementation of dictionaries
      • Red-black tree (Python)
      • AVL Tree (Python)
    • B-Tree
  • H Tree
  • Rope (python)
