In the first part, we created a chat application with Flask and jQuery which used polling. In this part, we will have a look at WebSockets (WS).

WebSocket Basics

WebSocket is a two-way communication protocol.

WebSocket is fully usable since 2011. You can use WebSocket on all modern browsers.

It had a W3C / WHATWG standard and was moved to IETF.

Scaling

A single server can handle \(2^{16} = 65536\) sockets per single IP address.1 You might want to limit the number of connections your app makes. Otherwise, it could happen that you can't ssh into your server anymore. For more details, see 1,2,3.
