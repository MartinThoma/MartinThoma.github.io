If Computer Problems Were Real

Sep 30, 2011 · by Martin Thoma

  • Funny 19
  • Video 28

Before the computer ... ... a memory was something you've lost with age ... an application was for employment ... a program was a TV show ... a cursor used profanity ... a keyboard was a piano ... a web was a spiders home ... a virus was the flu ... a CD was a bank account ... a hard drive was a long trip on the road ... a mouse pad was where a mouse lived ... a tree, leaf and root could be found in nature ... a path was a way and if you had a 3,5 inch floppy... ... you hoped nobody found out.
